# Mission: Agentic Applications

## Why

Land a professional role designing and building agentic AI systems. The user wants to be hirable as someone who can design, build, and defend production-grade LLM agent systems — with interview-ready theoretical depth and a demonstrable portfolio, starting from scratch.

## Success looks like

- Can explain and apply core theory from first principles: the agent loop, tool use, ReAct, planning, memory, multi-agent patterns, evaluation, and failure modes — backed by primary sources (papers, Anthropic/OpenAI/Google engineering posts).
- Can build, test, and iterate a non-trivial agent (tools + loop + memory) without a framework, then justify when a framework (e.g. LangGraph) is the right call.
- Has a portfolio-grade project in this workspace demonstrating production concerns: guardrails, observability, evals, cost/latency trade-offs, human-in-the-loop.
- Can pass design interviews on agentic systems: whiteboarding an agent architecture, naming failure modes, defending trade-offs.

## Constraints

- Start from scratch — no prior LLM/agent knowledge assumed; build up everything.
- Theory first, then build: mental model before implementation in each topic.
- Learn over multiple sessions; one concept at a time, verifying understanding before advancing.

## Out of scope

- Training or fine-tuning LLMs (weights-level work) — this is an applications mission.
- Deep ML/math prerequisites (transformers internals beyond what agent design needs).
- Specific vendor SDK trivia that changes quarterly — concepts first, APIs second.
