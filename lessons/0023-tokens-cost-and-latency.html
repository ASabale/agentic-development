Lesson 0023 · Phase 1 depth · ~12 minutes

Tokens, cost, and latency

Every extra beat of the loop is a bill and a wait. Agents are 4× chat. Multi-agent is 15×. Know why.

Your one win today Compute a back-of-envelope cost for a 10-step agent turn, and name the three clocks (queue, input processing, generation) so you can talk latency without waving at GPUs.

1 · Two meters, not one

Providers bill input tokens (the prefix you send) and output tokens (what the model emits, including thoughts and tool-call JSON). Output is usually several times more expensive per token than input. Cached input (next lesson) is cheaper still.

Because the harness resends the transcript, a 10-step agent does not cost 10× a one-shot. It costs the triangular number: step 1 sees 1k input, step 2 sees 1k+the last call, … step 10 sees almost the whole trace. Anthropic’s published ratios: agents ≈ 4× chat; multi-agent ≈ 15× chat.[1] Those are not moral numbers. They are what loops do to a transcript.

Interview lineflexibility is a rate card

Your envelope, every design review: expected steps × (avg input + avg output) × unit price, plus a p95 because retries (Factor 9) and reflections add turns. If you cannot write that product, you do not have a cost model.

A thinking budget is output. Reasoning models spend those tokens before the answer, and you pay the output rate for them.[2] Turn the budget down on lookups. The harness changes the bill too: Anthropic’s managed-agents comparison put two ways of wrapping the same kind of work at about $9 and about $200.[3] Quote the order of magnitude, then measure your own trace.

2 · Three clocks

ClockWhat it isHow agents blow it up
Queue / rate limitWaiting to even startParallel workers (0015) stampede the same key
Time-to-first-token (TTFT)Processing the prefix before any outputGrows with uncached input. Caching (0025) is a TTFT feature as much as a cost feature.
GenerationTokens sampled one after anotherLong CoT / “thinking” / huge JSON dumps. Output tokens are slow and pricey.

A workflow of three small calls can beat one “smart” agent on p95 latency even if the agent uses fewer total tokens — sequential beats plus TTFT each time vs one long generation. Measure. Do not argue from architecture diagrams.

Interview angle “This agent will be too slow / too expensive.” Strong: show the envelope, the 4×/15× citations, which clock dominates, what you’d cap (steps, output tokens, worker fan-out), and when you’d drop to a workflow. Weak: “we’ll use a smaller model” as the only lever.

3 · Retrieval practice

1. Why is a 10-step agent not “10 × one chat”?

Correct. Stateless replay. Cache blunts it; it does not flatten it to 1×.
No secret flag, no separate tool-meter. Triangular prefixes. Option 2.

2. Anthropic’s published multiples vs chat?

Correct. 90.2% was a quality delta on one eval (0015), not a price. Cache helps but was not that claim.
Do not turn 90.2% into a bill, and do not assume cache makes agents cheap. Option 3.

3. Long “thinking” traces hit which clock hardest?

Correct. Thoughts are output (then later input). Generation clock + the output rate card.
Not free, not fully parallel. Generation. Option 1.

4. A fair cost model for a design review names…

Correct. Envelope first. Seats and rented GPUs are a different conversation.
Seats and colo GPUs are not the agent rate card. Option 3.

The cost paragraphs in How we built our multi-agent research system. Then the vendor’s current price page for the model you would actually call — numbers move; the envelope does not.

5 · Lock it in

  • 4× / 15×. Triangular prefixes. Three clocks. Recite.
