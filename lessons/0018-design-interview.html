Lesson 0018 · Phase 5: Career · ~15 minutes

Design-interview drill

Forty-five minutes, one whiteboard, no framework name until you have earned it.

Your one win today Run a seven-move script on any “design an agent” prompt. After this page, do the drill out loud — in chat with me, or to a wall. Fluency here is fake until you speak.

1 · What they are testing

Not whether you have used LangGraph. Whether you can:

  • Refuse an agent when a workflow is enough (0001, 0003).
  • Draw the loop and the split of labor (0002).
  • Name failure modes and who owns them (0012, 0014).
  • Say how you would know it got better (0013).
  • Price the fancy options (0015, 0016) instead of defaulting to them.

Mission success criterion: “Can pass design interviews on agentic systems: whiteboarding an agent architecture, naming failure modes, defending trade-offs.” This lesson is that criterion as a script.

2 · The seven moves

  1. Restate the job and the user. What is the goal, who is accountable, what happens if it is wrong? If they cannot name a human owner, you just found the HITL requirement.
  2. Ask whether the path is enumerable. If yes, pick a workflow pattern by name (chain / route / parallel / orchestrator-workers / evaluator-optimizer). Stop climbing. If no, you have an agent.
  3. Draw the five beats. Model / harness. Tools as structured outputs. Observation paired by id. Do not skip this drawing; it is how they see you have built one in your head.
  4. List tools as an ACI. Three to seven verbs, risk-rated (read / write / irreversible). High-risk: interrupt between select and invoke. Descriptions are prompt surface.
  5. Context and memory. What is in the window every turn? What is a pointer? What is a file? What must be exact (ids) vs searchable?
  6. Guardrails + evals in the same breath. Layered defense; a held-out task set with code graders on world-state; LLM-judge for tone, audited; regression suite.
  7. Cost ladder. Tokens per job, latency, 4× / 15× if they push multi-agent. Framework only if you need checkpointers or graph joins. Cap steps (Factor 10).
Catchphrases that score “Who picks the next step?” · “The API does not execute the function.” · “Valid JSON is not a correct refund.” · “Grade the world, not the path.” · “Multi-agent is extra windows, mostly extra tokens.” · “A computer cannot be held accountable.”

3 · A worked stub (do not memorize the domain — memorize the moves)

“Design an agent that handles inbound support tickets for a SaaS billing team.”

  • Job: resolve or escalate. Owner: billing lead. Wrong refund is money.
  • Path: most tickets are enumerable (lookup invoice → apply policy → reply). That is routing + chaining, with an agentic pocket for “I don’t recognize this.”
  • Loop: only in the pocket. Tools: lookup_account, list_invoices, draft_reply, issue_refund (HITL), request_human.
  • ACI: refund is irreversible → pause before invoke. Observations compact. No raw SQL.
  • Memory: ticket id and policy version are exact state. Wiki is search-as-tool.
  • Evals: 50 anonymized tickets, expected world-state, policy code-grader, tone judge on 20-human gold, jailbreak set.
  • Cost: default workflow; agent pocket capped at 8 steps; no multi-agent.

4 · Retrieval practice

1. First question, after restating the job?

Correct. That is the agent/workflow test. Databases and subagents come after, if ever.
Do not open with vendors or multi-agent. Enumerable path? Option 2.

2. You mention a framework unprompted. Risk?

Correct. Earn the runtime. Fifty lines first, checkpointers if needed. The interviewer has read Anthropic too.
It is not the opening, and the real risk is skipped ownership. Option 3.

3. Best paired sentence with “we’ll add evals”?

Correct. That sentence is lesson 0013 in one breath. Thumbs and Sev-1s are lagging signals.
Prod vibes are not a development eval. Option 1.

4. They push “make it fully autonomous.” Your line?

Correct. IBM slide. Tools-in-a-loop is not a staff replacement. Pause on irreversible verbs.
Do not drop HITL, and extra agents are not accountability. Option 3.
