Lesson 0024 · Phase 3 depth · ~12 minutes

Failure modes

Agents fail in named ways. Interviews reward the catalog, not optimism.

Your one win today List six failure modes from memory, and for each name whether the fix is context, ACI, control flow, or eval. This is the other half of “how would you design it?”

1 · Weng’s three, still true

Lilian Weng, 2023, closing her agent survey with limitations that have not expired:[1]

  1. Finite context. The bandwidth is the window. Vector stores are not full attention (lessons 0004, 0009).
  2. Long-horizon planning is weak. Models do not adjust plans under surprise as well as a person. Factor 10 is the production response: smaller jobs.
  3. Natural language is a flaky interface. Formatting errors, refusals, “rebellious” failures to follow the schema. A shocking fraction of demo code is parsers. Structured Outputs (0011) exist because of this row.

ReAct’s own analysis of success and failure (the paper’s appendix) is worth knowing exists: search-fail vs reasoning-fail vs hallucination on HotpotQA. The move is to name which, not to say “we’ll add more agents.”[2]

OWASP’s December 2025 agentic top 10 is the named list beyond this table: tool misuse, memory poisoning, and the rest, with prompt injection as one row.[3] Lesson 0027 owns the injection row. Use the top 10 so you do not stop at hallucination.

Interview angle After you draw the architecture they will ask “how does this fail?” Answer in this catalog, one sentence each, with a lever. If you only list hallucination you sound like 2023. If you include spin, early victory, injection, and grader bugs you sound like you’ve read a postmortem.

3 · Retrieval practice

1. Weng’s “reliability of the NL interface” is why we…

Correct. Structured Outputs help shape. Semantic misses and refusals remain. Harness code stays.
Don't ban tools, don't blame the tokenizer. Schemas + parsers. Option 3.

2. Early victory is fixed first by…

Correct. 0017: verify before exit. Prompts help; unenforced humility does not.
Prompt-only humility and ungrounded critics are weak. Check in code. Option 1.

3. Same tool errors three times. Next?

Correct. Factor 9. Spin is a named mode. Caps are control flow, not vibes.
Unbounded retry is the bug. Deleting the tool dodges the job. Option 2.

4. Best one-line after drawing an architecture?

Correct. Catalog + levers. Bigger is not a failure mode, and schema ≠ truth (0011).
Hallucination-only and “cannot fail” are junior. Option 3.

4 · Read next (primary source)

Weng, LLM Powered Autonomous Agents — the Challenges section (~5 min). Then skim ReAct’s failure-mode appendix if you still have appetite: arXiv:2210.03629.

5 · Lock it in

  • Six modes, four lever types (context, ACI, control flow, eval). Cover and recite.
  • New glossary terms: early victory, goal hijack, spin.
