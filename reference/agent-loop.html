The agent loop

One page. Recite it before every later lesson.

Definition An LLM agent runs tools in a loop to achieve a goal. [Willison 2025]

Split of labor

SideDoesDoes not
ModelRead context; emit text or a structured tool call; decide when it is done.Execute functions; hold state between calls; see your implementation.
HarnessBuild context; parse calls; execute functions; append observations; loop or stop; persist state.Choose the next tool (that is the model's job, in an agent).

Five beats of one step

  1. You send context + tool schemas to the model.
  2. The model returns a tool call (name, arguments, id) — or a final answer.
  3. Your harness executes the function.
  4. You append the observation, tagged with the same id.
  5. You call again. Repeat until a final answer, a cap, or a human interrupt.

Source: OpenAI function calling. Anthropic’s equivalent: stop_reason: tool_use → your tool_result blocks → call again.
