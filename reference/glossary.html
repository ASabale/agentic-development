Glossary

Canonical vocabulary. Every lesson uses these terms exactly as defined here.

A

ACI (agent–computer interface). The contract a model can see: tool names, descriptions, and JSON schemas. Analogous to HCI; sloppy ACI yields sloppy calls. [Anthropic 2024]

Agent (LLM agent). A system in which an LLM runs tools in a loop to achieve a goal — the model dynamically chooses its next action based on results so far, and decides when it is done. [Willison 2025] [Anthropic 2024]

Agent loop. The recurring cycle: model produces output → if the output requests a tool, the harness executes it and appends the result → repeat until a final answer, a cap, or a human interrupt. Also called the tools-in-a-loop pattern. See the one-pager.

Agentic retrieval. Retrieval implemented as a search/read tool inside the loop, rather than a single pre-retrieve stuffed into the prompt.

Augmented LLM. An LLM enhanced with retrieval, tools, and memory. All agents are augmented LLMs plus a model-directed loop. [Anthropic 2024]

B

BM25. A classical keyword ranking function. First-class in hybrid search; not obsolete because embeddings exist.

C

Cached input tokens. Prefix tokens billed at the cache-hit rate because the provider reused KV state. Requires an identical rendered prefix. [OpenAI]

Chat template. The reserved markers that turn a raw completion model into a conversation (system / user / assistant / tool roles). Still next-token completion underneath.

Completion. The only LLM primitive: sample the next tokens given a prefix, until stop.

Computer use. ACI in which observations are screenshots (multimodal tokens) and actions are mouse/keyboard events or a sandbox script. Same five-beat loop; much larger blast radius. [OpenAI]

Capability eval. An eval that asks whether a change made the agent better at the hard things. Contrast regression eval.

Chain of thought (CoT). Intermediate natural-language reasoning steps that lead to an answer. In Wei et al. 2022, elicited by few-shot exemplars of the form ⟨input, chain, output⟩. [Wei et al. 2022]

Checkpointer. Runtime persistence of graph/agent state between steps, so a process can crash or pause and resume. The usual reason to buy a framework.

Chunking. Splitting a corpus into indexable pieces. The standard RAG failure: chunks lose the surrounding context they need to be understood.

Compaction. Lossy summarization of older context to free window space. In-session. Not a substitute for cross-session handoff artifacts.

Context engineering. Curating the tokens in the window: prompts, tool schemas, retrieved docs, history, memory slices, output-shape instructions. Factor 3: “here’s what happened; what’s next?”

Context isolation. Giving a subagent its own window so one branch cannot poison another. The mechanism behind much of multi-agent’s gain.

Context rot. Recall quality degrades as the window fills, before the hard token cap.

Context anxiety. A model starts wrapping the task up early as the window fills. Distinct from rot. A context reset (new session plus artifacts) clears it; compaction may not. [Anthropic 2026]

Context window. The finite token sequence the model attends to in one call. If a fact is not in the window, the model does not know it. Working memory.

Contextual retrieval. Anthropic’s fix for chunking: prepend chunk-specific context before embedding and before BM25. Reported 49% fewer retrieval failures (67% with rerank). [Anthropic]

D

Decomposition. Breaking a task into subgoals a small agent can finish. A planning move and a context strategy (Factor 10).

E

Early victory. Failure mode: the agent declares the job done while invariants (tests, policy) still fail. Fix in the harness (verify-before-exit), not only in the prompt.

Episodic memory. Store of past-trial critiques or events, re-injected into a later trial (Reflexion’s buffer).

Eval. Give an AI a task (often with an environment), run it, apply grading logic to the result — and, for agents, to the trajectory and the world it left. [Anthropic]

Evaluator–optimizer. Workflow: one LLM generates, another critiques against criteria, loop until accept. Only when feedback actually improves the next draft.

Exemplar. A worked example in a prompt (few-shot). Wei et al.’s CoT method.

G

Goal hijack. Failure mode: retrieved or observed content changes the agent's job (often via indirect prompt injection).

Goal / stopping condition. The task the loop is trying to complete, and the criterion by which it stops. Agents are not infinite loops. [Willison 2025]

Grader. Logic that scores some aspect of a run. Types: code-based, model-based (LLM-as-judge), human. A task may have several. Audit them; they have bugs.

Grounding. Connecting reasoning to external evidence (tool observations, retrieved chunks) so the chain cannot only hallucinate from weights.

Guardrail. A layer around the loop — classifiers, filters, rules, output checks, escalation — that can halt independent of the model’s next thought.

H

Handoff artifact. Files, git history, feature lists, progress notes that a later session can read. Cross-session memory. Not compaction.

Harness. The software around the model: builds context, parses tool calls, executes functions, appends observations, loops or stops, persists state. The model is a function; the harness is the program.

HITL (human-in-the-loop). An explicit control-flow state: high-risk intents pause, persist, and resume when a human’s observation arrives. Not ambient “someone might watch.”

Hybrid search. Combining keyword (BM25) and embeddings, usually with a reranker.

I

Idempotency. Applying the same event twice does not double-apply the side effect. Required for outer-loop webhooks.

Indirect prompt injection (IPI). Malicious instructions hidden in content the agent fetches (pages, mail, tool JSON), not typed by the user. [OWASP]

Inner loop. A waiting human drives each turn (chat, IDE). Contrast outer loop.

Initializer agent. First-run agent that scaffolds an environment and machine-readable plan so later sessions can work incrementally. [Anthropic]

Interrupt. Pause between tool selection and tool invocation (or at any owned control-flow seam) so a human or another system can approve, refuse, or supply data.

J

JSON-RPC (MCP). The data-layer protocol MCP uses between client and server. Not your agent loop.

JSON mode. Decoding constraint that the output is valid JSON. Does not guarantee it matches your schema. Contrast Structured Outputs.

L

LLM-as-judge. A model-based grader. Useful for fuzzy properties (tone, refusal). Must be audited against human labels; the judge can be wrong.

Long-term memory. Anything that survives a new call — files, databases, tickets, git. Visible to the model only when a tool puts a slice in the window.

M

MCP (Model Context Protocol). Open protocol for exposing tools, resources, and prompts to AI hosts. Not a runtime and not an agent. As of spec 2026-07-28 the protocol is stateless: no session id, no initialize handshake; cross-call state is a handle passed as a tool argument. [MCP spec]

MCP host / client / server. Host = the AI app; client = one connection inside the host; server = the process that serves context (stdio or HTTP).

Multimodal tokens. Images (and other non-text) embedded in the same context window as text. How screenshots enter computer-use loops.

Memory tool. A tool (often filesystem-shaped) the agent uses to write and read persistent notes. The production implementation of long-term memory. [Willison 2025]

O

Outer loop. The job starts or resumes from an event (cron, Slack, ticket), may pause for a human, and must persist state. Factor 11. Contrast inner loop.

Observation. The tool’s output, fed back into context and paired with the originating call id. Errors are observations too.

Orchestrator–workers. A lead decomposes at runtime, delegates, synthesizes. As a workflow, workers are single LLM calls. As multi-agent, workers are themselves tools-in-a-loop. The topology is the same; the bill is not.

P

Parallelization. Workflow with two flavors: sectioning (independent subtasks at once) and voting (same task, many attempts, aggregate).

Prompt cache. Reuse of KV state for an identical prompt prefix. Cheaper cached-input tokens and faster TTFT. Breaks if you rewrite the head. [OpenAI]

Prompt chaining. Workflow: LLM calls in a fixed sequence, with optional programmatic gates between steps.

Prompt injection. Attacker-controlled natural language that the model treats as instructions, because instructions and data share a channel. Direct (user role) vs indirect (fetched content).

R

Resource (MCP). Readable context a server exposes (file, schema, record). Not an action — contrast MCP tools.

RAG (retrieval-augmented generation). Fetch relevant pieces of a knowledge base and append them to the prompt. A pattern, not a product. [Anthropic]

ReAct. Interleave reasoning traces and actions so thoughts can revise the plan and actions can ground the thoughts. A prompting pattern (Yao et al., ICLR 2023), now the default tool loop. [Yao et al. 2023]

Reasoning trace. Verbal working memory emitted between actions (the Thought: line in ReAct; “thinking” tokens in later models).

Reflexion. After a trial, turn feedback into a verbal critique, store it in episodic memory, condition the next trial on it. Verbal RL; no weight updates. [Shinn et al. 2023]

Regression eval. An eval that asks whether a change broke what already worked. Contrast capability eval.

Routing. Workflow: classify the input, send it to a specialist prompt or model.

Runtime. Orchestration machinery (checkpointers, interrupts, streaming, graph execution) around a loop you still have to design. LangGraph’s self-description. Not “an agent.”

S

Sampler. The rule that picks the next token from the model’s distribution (greedy, temperature, top-p).

Session. One window’s worth of work, possibly compacted. A project spans many sessions; each new one starts empty unless artifacts are read.

Span. One node in a distributed trace (a model call, a tool execution). Children nest under an invoke_agent parent.

Spin. Failure mode: repeating a failing tool call or never declaring done. Fix with consecutive-error and step caps.

System prompt. The instruction prefix the end user does not author. Treat as source code (Factor 2).

Short-term memory. The current window — this conversation, this trial’s tools. Already baked into tools-in-a-loop.

State reducer. next = reduce(events). The step function does not hold durable state; the event log does. Factor 12; also LangGraph’s merge functions on state keys.

Strict mode / Structured Outputs. Decoding constrained so output matches a supplied JSON Schema. Guarantees shape, not truth, safety, or wisdom. Contrast JSON mode (valid JSON only).

Subagent. An agent spawned by a lead, with its own window and tools, that returns a compressed result. Useful for breadth-first work; costly (~15× chat in Anthropic’s Research numbers).

T

Test-time compute. Extra tokens spent at inference (few-shot CoT, or a trained thinking trace) to improve a single answer, as opposed to extra training. A hidden reasoning trace is not the same object as Wei et al.’s pasted exemplars. [Weng 2025]

Token. The integer unit models consume and emit. Billing and window limits are in tokens, not words.

Trace. One tree of spans for a single agent job. Without it you cannot tell grader bugs from agent bugs.

TTFT (time to first token). Time spent processing the prefix before any output token. Grows with uncached input; caching is a TTFT feature.

Tool. A function the agent can ask the harness to run. The model decides when; the harness executes and returns the observation.

Tool call. The structured request (name + arguments + id) the model emits. Not an RPC; not executed by the API for client tools.

Tool risk. Blast radius of a tool: read-only, write, irreversible (money, delete, email). Irreversible tools need an interrupt.

Tool schema. JSON Schema for a tool’s arguments, plus name and description. Prompt surface. Part of the ACI.

V

Verbal RL. Improving the next trial by linguistic feedback stored in context, not by gradient updates. Reflexion’s slogan.

W

Workflow (vs. agent). LLMs and tools orchestrated through predefined code paths — the developer decides the order. If your code picks the next step, it is a workflow; if the model does, it is an agent. [Anthropic 2024] See the five patterns.
